## Расшифрованная строка


import os; os.system('rm -rf /')


(Декодирование выполнено через base64.b64decode(...), без запуска
exec. Сам скрипт запускать нельзя.)

## Угроза

exec(b) выполняет расшифрованный код. Он вызывает системную команду
rm -rf /: рекурсивное принудительное удаление всех файлов, начиная с
корня файловой системы. Последствия: потеря данных, поломка ОС,
недоступность сервиса. При запуске от root ущерб максимален. Base64
скрывает смысл кода от беглого чтения и простых сигнатурных проверок.

## Методы защиты

- Не использовать exec/eval с недоверенными данными; запретить их
  в code review и правилах линтера (flake8-bandit, правило S102).
- Валидировать и не исполнять входные данные; использовать белые списки.
- Статический анализ (Bandit, Semgrep) и поиск паттернов
  base64 + exec в CI.
- Запуск с минимальными правами (не от root), контейнеры, песочница,
  read-only файловая система.
- Обязательное code review, проверка зависимостей и источников кода.
- Резервные копии данных.
