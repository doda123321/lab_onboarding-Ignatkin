# Диагностика клиентского компьютера (часть 2: аудит)

Скрипт `pc_info.command` собирает сведения о компьютере и сверяет установленные программы с эталонными списками. Он формирует рекомендации в `pc_report.txt`. Запуск: двойной щелчок по файлу (macOS).

## Какие категории базового ПО выбраны и почему
Выбран минимум для офисной работы:
- **Офисный пакет** (Word, Pages, LibreOffice и др.) нужен для документов.
- **Браузер** (Chrome, Firefox, Safari и др.) нужен для веб-сервисов и почты.
- **Просмотр PDF** (Acrobat, PDF Expert, Preview и др.) нужен для чтения документов.
- **Архиватор** (Keka, The Unarchiver и др.) нужен для вложений в почте.
- **Антивирус** (Kaspersky, ESET и др.) нужен для защиты рабочего места.

Safari, Preview и Archive Utility входят в macOS, и в отчёте это отмечается: их наличие не означает, что рабочее место настроено.

## Признаки излишнего ПО
- Игры и платформы: Steam, Epic Games, GOG, Origin, Ubisoft, Battle.net, Riot, Roblox, Minecraft, слова game/gaming.
- Торрент-клиенты: torrent, Vuze, Transmission.
- Мессенджеры для личного общения: Discord, Telegram, WhatsApp, Viber, Skype.
- Развлекательные инструменты: Wallpaper Engine, OBS, Soundpad, VLC, Spotify, IINA.

Скрипт не утверждает, что программу нужно удалить. Он рекомендует администратору обратить на неё внимание.

## Как проверялась работоспособность
- Ветка «не найдено»: в обычном запуске на моём компьютере не найден антивирус, и скрипт выдал рекомендацию его установить.
- Ветка «найдено»: запуск `EXTRA_APPS="uTorrent|Kaspersky|OBS|Wallpaper Engine" ./pc_info.command` добавляет тестовые названия в список. Они попали в рекомендации по излишнему ПО, а Kaspersky закрыл категорию «Антивирус». Результат сохранён в `test_report.txt`. В тестовом отчёте есть пометка о тестовых данных.
- Защита от пустых значений: перед каждым блоком переменные очищаются, при пустом результате в отчёт выводится «не удалось получить данные».

## Ограничения
- Сверка идёт по названиям приложений в папках `/Applications`, `~/Applications` и системных папках. Программы, установленные в другие места или через Homebrew, не учитываются.
- Поиск по подстроке даёт ложные срабатывания: например, встроенное приложение Apple «Games» попадает в игры из-за слова game в названии.
- Скрипт не определяет, когда программу запускали в последний раз.
- Вместо Windows-версии (.bat) сделана версия под macOS с разрешения преподавателя.
