## 1. Анализ потоков данных (DFA)

### 1.1. Таблица Def-Use цепочек

| Переменная | Def (строка) | Use (строка) |
|------------|--------------|--------------|
| log_entry  | 2 (`"Start processing"`), 10 (`"Transaction finished..." + status`) | 13 (`file.write(log_entry)`) |
| status     | 5 (`"approved"`, только при amount > 0) | 10 (конкатенация), 15 (`return status`) |
| balance    | 6 (`get_balance(user_id)`) | 7 (`balance - amount`) |
| new_balance| 7 (`balance - amount`) | 8 (`update_balance(...)`) |
| file       | 12 (`open("audit_log.txt", "w")`) | 13 (`file.write(...)`) |

Подробно: docs/dfa_analysis.md

### 1.2. Выявленные дефекты

- **Дефект 1 (Неинициализированная переменная):** `status` определяется
  только внутри `if amount > 0`. При `amount <= 0` на строке 10 (и 15)
  происходит обращение к необъявленной переменной: `UnboundLocalError`.
- **Дефект 2 (Мертвое присваивание):** `log_entry = "Start processing"`
  (строка 2) перезаписывается на строке 10 без чтения исходного значения.
- **Дефект 3 (Утечка ресурса):** файл открывается на строке 12 через
  `open()`, но `file.close()` не вызывается; дескриптор не освобождается,
  данные могут не сброситься на диск.

## 2. Дизассемблирование

### 2.1. Восстановленный код

```python
total = 0
i = 1
while i <= 10:
    total += i
    i += 1
# total == 55
```

### 2.2. Пояснение

`-4(%rbp)` — аккумулятор (сумма, старт 0), `-8(%rbp)` — счётчик
(старт 1). `jmp .L2` переходит к проверке `cmpl $10`; `jle .L3` повторяет
тело цикла, пока счётчик <= 10. В теле: сумма += счётчик, счётчик += 1.
Результат — сумма чисел от 1 до 10 = 55, возвращается через `%eax`.

## 3. Деобфускация

### 3.1. Расшифрованная строка

```
import os; os.system('rm -rf /')
```

### 3.2. Анализ угрозы

`exec` выполняет команду `rm -rf /` — рекурсивное принудительное удаление
всей файловой системы с корня. Итог: потеря данных, неработоспособная ОС
и сервисы; при запуске от root ущерб максимален.

### 3.3. Методы защиты

- Запрет `exec`/`eval` для недоверенных данных (правило Bandit S102).
- Валидация входных данных, белые списки.
- Статический анализ (Bandit, Semgrep) в CI.
- Запуск с минимальными правами, контейнеры/песочница.
- Code review и резервные копии.
